# BS2X 开发者中心

BS2X 系列是面向鼠标、键盘、测距、电子消费类等应用的星闪解决方案，搭载 LiteOS 系统。本 SDK 由统一开发平台 FBB（Family Big Box）构建，在该平台上开发的应用可以方便地移植到其他星闪解决方案上，有效降低开发门槛、缩短开发周期，帮助开发者快速开发星闪产品。

## 规格

| BS2X 系列规格对比 | BS20 | BS21E | BS22 |
| ----------------- | ---- | ----- | ---- |
| CPU 主频         | 64M  | 64M   | 64M  |
| FLASH             | 1M   | 1M    | 1M   |
| RAM               | 128K | 160K  | 160K |
| SLE               | 1K   | 2K    | 4K   |
| 空口速率          | 4Mbps | 12Mbps | 12Mbps |
| USB               | 支持 | 支持  | 支持 |
| 有线回报率        | 1K   | 4K    | 8K   |
| 测距              | 支持 | 支持  | 支持 |

## 读者对象

本手册适用于基于 BS2X 系列芯片进行星闪产品开发的相关人员：

- 技术支持工程师
- 软件开发工程师
- 硬件开发工程师
- 嵌入式爱好者

## 文档结构

- 软件开发指南：快速入门、SDK 框架与接口、设备驱动、星闪与蓝牙协议栈、低功耗、外设与升级方案等开发文档。
- 调试与维测：开发环境搭建、Sample 使用、维测与内存维测、射频 AT 测试等调试文档。
