### 修复总结

共修改 **4 个文件**，修复 **5 类 TLV 解析整数溢出/越界漏洞**：

#### 漏洞 1 & 2：TLV 迭代整数溢出 + 越界读（严重）

**文件**：dongle `sle_ota_cmd_handler.c` — `sle_ota_connect()` 和 `sle_ota_disconnect()`

| 修复点 | 修改内容 |
|--------|----------|
| `body_offset` 类型 | `uint16_t` → `uint32_t`，防止 `body_offset + 3 + length` 溢出 |
| `body_len` 与 `length` 一致性 | 新增校验 `sle_link_frame->body_len <= length - offsetof(body)` |
| TLV length 边界 | 新增校验 `sle_link_body->length <= body_len - body_offset - 3`，超出则 break |
| 循环条件 | 改为 `body_offset + 3 <= body_len`，确保可读取 TLV 头部 |
| TLV value 读取 | 新增 `sle_link_body->length >= N` 前置检查，防止读取超出 TLV value 范围 |

#### 漏洞 3：`sle_ota_send_data` 忽略 `length`（高）

**文件**：dongle `sle_ota_cmd_handler.c`

| 修复点 | 修改内容 |

| `len` 与 buffer 一致性 | 新增 `len > length - WRITE_REQ_DATA_INDEX` 校验，防止越界读 |

#### 漏洞 4：`sle_ota_write_cmd` 忽略 `length`（高）

**文件**：RCU `sle_ota_cmd_handler.c`，修复方案同漏洞 3

#### 漏洞 5：`g_reassembly_len` 的 `uint16_t` 加法溢出（高）

| 修复点 | 修改内容 |
